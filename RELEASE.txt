================================================================================
  2. РЕЖИМЫ ПАКОВКИ
================================================================================

  --zero-key  (SHIP mode, дефолт для wide release)
        Baked KFPL_KEY[32] = все нули.
        Launcher декриптит ТОЛЬКО когда backend инжектит env
        AH_KFPL_KEY_B64 (или _HEX) на Play time.
        Двойной клик на WinRuntimeHost.exe без env → decrypt fail → exit.
        Пират не запустит.

  (без --zero-key)  DEV/LOCAL mode
        Baked KEY = реальный fresh random.
        Launcher декриптит из baked (env необязателен).
        Двойной клик работает. Удобно для локального теста, НЕЛЬЗЯ для wide.


================================================================================
  3. КАК ЗАПАКОВАТЬ (правильный ship путь)
================================================================================

    cd C:\arenaREmake\arenahack
    python scripts\make_release_zip.py --zero-key --version 1.0.X

  Опции make_release_zip.py:
    --version 1.0.X          строка версии для формы Upload
    --channel stable         канал (stable / beta / dev)
    --no-overlay-build       пропустить пересборку overlay (используем
                             существующий build\ah_overlay.exe)
    --zero-key               ship mode (см. п.2)

  Что скрипт делает по шагам:
    1) Собирает overlay (или пропускает если --no-overlay-build).
    2) launcher\bake.py:
       - генерит fresh random 32-byte KFPL key
       - пакует build\ah_overlay.exe → launcher\embed\bundle.kfpl
         (AES-256-GCM, magic "AHKF")
       - в --zero-key режиме прописывает ZEROS в KFPL_KEY[32] launcher\src\ah_launcher.c
       - печатает KFPL key в stdout — сохранить, это единственное место!
    3) launcher\build.bat:
       - собирает stub → launcher\build\WinRuntimeHost.exe (168 KB)
    4) scripts\vmprotect_wrap.py:
       - VMProtect_Con.exe wraps launcher stub in-place
       - virtualize resolve_key + aes_gcm_decrypt (Ultra)
       - размер после wrap: 13-15 MB
    5) Embed step (новое):
       - stub bytes + bundle.kfpl bytes + AHBE trailer(12B) → stage\WinRuntimeHost.exe
    6) Копирует db\*.bin в stage.
    7) Zip: releases\WinRuntimeHost.zip


================================================================================
  4. КЛЮЧ (важно — сохранить сразу!)
================================================================================

  make_release_zip.py печатает 2 строки:
    hex:    <64 hex>
    b64:    <44 base64 with padding>

  Сохранить b64 — он идёт в форму Upload release, поле KFPL KEY.

  Каждый прогон make_release_zip.py = fresh random key. Значит:
    - Собрал → взял key → залил на форму — все три должны быть одной парой.
    - Если пересобрал → старый key больше не подходит, залей новый zip + новый key.

  Хочешь re-use ключ между сборками — можно, но потребуется править
  launcher\bake.py передавать --key-hex <старый>. Дефолт — всегда fresh.

================================================================================
  6. КАК ЭТО РАБОТАЕТ У ЮЗЕРА
================================================================================

  1) юзер жмёт Play в KoenFlow Launcher
  2) launcher из backend получает kfplKey, скачивает zip, распаковывает в
     %LOCALAPPDATA%\KoenFlowLauncher\products\arena-breakout-esp\current\
  3) launcher вызывает CreateProcessAsUser(WinRuntimeHost.exe, ...) elevated
     с env AH_KFPL_KEY_B64=<этот key>
  4) WinRuntimeHost.exe:
       - VMProtect stub стартует
       - resolve_key читает env → нашёл валидный key
       - self-read tail: seek к end, читает AHBE trailer, извлекает
         bundle bytes past PE end
       - aes_gcm_decrypt(bundle) → plaintext = overlay bytes
       - drop в %TEMP%\<12hex>.exe
       - CreateProcessW DETACHED_PROCESS | CREATE_NO_WINDOW
       - WaitForSingleObject → удаляет tmp при exit
  5) Overlay сам:
       - anti-debug + AMSI patch + ETW blind (DhInitHardening)
       - D3D11 + DirectComposition + ImGui window (WDA_EXCLUDEFROMCAPTURE)
       - reader thread: kdu#26 → sysCR3 → EPROCESS walk → UAGame proc
       - waiting loop до появления UAGame → ATTACH LATCH → GWorld → ACE decrypt

  Юзер видит только один exe (18 MB), сам он не запустит его вручную —
  без env key baked=zeros = decrypt fail = silent exit.


================================================================================
  7. ROLLBACK / ITERATIONS
================================================================================

  Каждый прогон make_release_zip.py:
    - перезаписывает releases\WinRuntimeHost.zip
    - меняет KFPL key (fresh random)
    - переписывает launcher\src\ah_launcher.c KFPL_KEY[32]

  Если хочется сохранить старый zip:
    copy releases\WinRuntimeHost.zip releases\WinRuntimeHost-1.0.13.zip
  перед прогоном следующей сборки.

  Активная версия на бэкенде переключается флагом Activate now в форме.
